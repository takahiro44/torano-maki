# 文字起こし検証（ノートPCのCPUで実用になるか）

`faster-whisper` をCPUで動かし、**モデルサイズごとの精度と所要時間**を測る。

目的は「DGX（ARM64 + CUDA）を使わずに済ませられるか」の判断材料を出すこと。
経緯は `docs/decisions.md` の
「音声認識は `faster-whisper` の `medium` をCPUで使う」を参照。

**backend とは独立した uv プロジェクト。** 未確定のライブラリを
`backend/uv.lock` に入れないため分離している（`experiments/tts` と同じ方針）。

## なぜ faster-whisper か

- **PyTorch を必要としない**（CTranslate2 + onnxruntime）。`.venv` は数百MB で済み、
  埋め込み用の torch 3〜4GB を各自がもう一組入れる事態を避けられる
- 音声のデコードに PyAV を使うため、**ffmpeg のバイナリを別途入れなくてよい**。
  Windows で詰まりやすい箇所を1つ減らせる
- int8 量子化で CPU 実行が現実的な速度になる

## 実行

```bash
cd experiments/stt
uv sync
uv run test_stt.py --model small
```

モデルは初回のみ Hugging Face からダウンロードされる（`small` 約0.5GB /
`medium` 約1.5GB / `large-v3` 約3GB）。`~/.cache/huggingface` に入るので
リポジトリには残らない。

| オプション | 既定 | 用途 |
|---|---|---|
| `--model` | `small` | `tiny` / `base` / `small` / `medium` / `large-v3` |
| `--audio` | `tts-demo/output/sales_demo_perturn.wav` | 対象の音声 |
| `--reference` | `tts-demo/scripts/01_order_entry.json` | CERの基準にする台本 |
| `--compute-type` | `int8` | `int8` / `int8_float32` / `float32` |
| `--vad` | off | 無音区間の除去を有効にする（通常は指定しない） |
| `--no-reference` | off | CERを計測しない |

結果は `output/<model>.json` に出る（**git管理外**）。
形式は `backend/app/services/transcription.py` の `Transcript` と揃えてあるので、
本実装へ移すときに変換を挟まなくてよい。

## 正解テキストについて

人手の書き起こしは用意していない。この音声は `tts-demo/scripts/01_order_entry.json` の台本から
TTSで合成したものなので、**台本がそのまま正解**になる。

CERは比較前に句読点・全半角・空白を落としている（表記の差を誤りに数えないため）。
音声と台本が対応していない場合は文字数の比で検知して警告を出す。
`experiments/tts/output/test_sales_dialogue.wav` は別の台本なので、
これを測るときは `--no-reference` を付けること。

## 検証に使う音声

**`tts-demo/output/sales_demo_perturn.wav`（8分50秒）を使う。**

`sales_demo.wav`（chunkモード）は継ぎ目で声質と音量が変わる。
その音声で精度を測ると、**文字起こしの性能なのかTTSの乱れなのか切り分けられない。**
per-turn モードは発話ごとにプリセット音声を名前で固定するので話者が入れ替わらない。

## 測定結果（Windows 11 / x86_64 / 8コア / 32GB / int8 / VADなし）

対象: `sales_demo_perturn.wav`（8分50秒 = 530秒、2話者の商談）

| 設定 | 所要時間 | 実時間比 | CER | 欠落 | 納期 | 代替 | 新人 | FAX | Excel |
|---|---|---|---|---|---|---|---|---|---|
| （正解） | — | — | — | — | 2 | 1 | 1 | 6 | 4 |
| `small` | 3分43秒 | 2.4倍速 | 5.8% | 0字 | 0 | 0 | 0 | 0 | 0 |
| `small` + 用語集 | **2分42秒** | 3.3倍速 | 5.7% | 0字 | 0 | 0 | 0 | 0 | 0 |
| `medium` | 7分12秒 | 1.2倍速 | 4.1% | 0字 | 2 | 1 | 1 | 5 | 0 |
| **`medium` + 用語集** | 7分29秒 | 1.2倍速 | **3.1%** | 0字 | **2** | **1** | **1** | **6** | **4** |
| `large-v3` | 12分3秒 | 0.7倍速 | 7.3% | 0字 | 2 | 2 | 1 | 0 | 0 |

※モデル読み込み（2〜11秒）は所要時間に含めない。

### 結論

**`medium` + 用語集 + VADなし を採用する。**

- 残る誤りはほぼ表記ゆれ（`とき`→時 / `あと`→後 / `一`→1 / `延`→伸）で、実害がない
- 業務用語（納期・代替・新人・FAX・Excel）を**すべて正しく取れた唯一の構成**
- 8分50秒の音声を7分半。非同期ジョブ前提（CLAUDE.md 6章）なので許容範囲

速度が要るなら `small` + 用語集（2分42秒）。ただし `納期`→脳記、`代替`→大体、
`新人`→信じん が残るため、後段のLLMでの訂正が前提になる。

### ⚠️ large-v3 は最悪だった

**大きいモデルほど良いとは限らない。** `large-v3` は12分かけてCER 7.3%と、
`small` より悪い。原因は2つ。

1. `FAX`→ファックス、`Excel`→エクセル とカタカナに戻る（用語集なしでは medium も同様）
2. **無い言葉を作る。** 「あの商品は別に出てくるんですか実」のように
   11文字の幻覚が混入した。欠落とは逆に、**存在しない情報が増える**

営業ナレッジとして、幻覚は欠落と同じくらい危険。**検証せずに
「large が一番良いはず」で選ばなくてよかった。**

## VADは切ること（重要）

`vad_filter` を有効にすると**発話が丸ごと消える。**

| medium（旧音声） | 所要時間 | CER | セグメント数 | 欠落 |
|---|---|---|---|---|
| VADあり | 461.9秒 | 5.2% | 61 | **41字（14秒分）** |
| VADなし | 445.3秒 | **3.5%** | 118 | なし |

VADが長いセグメントを作らせ、その中で発話が出力されなくなる。
消えたのは「納期を延ばしてもらったり代替品を提案したり」という、
**営業ナレッジとして最も価値のある一文**だった。しかもCERの上では改善に見える。

比較に使ったJSONはローカルの `output/old_audio/` に保存してある（git管理外）。

## 誤りの種類と、後段のLLMで直せるか

| 種類 | 例 | LLMで直せるか |
|---|---|---|
| 表記ゆれ | `FAX`→ファックス、`一`→1 | そもそも実害がない |
| 同音の誤変換 | `納期`→脳記、`代替`→大体 | **直せる**（音が保たれている） |
| 固有名詞 | `SMILE V 2nd Edition`→スマイルVセカンドエディション | **直せる。ただし製品マスタが要る**（文脈推論では無理） |
| **欠落** | 14秒分が消える | **直せない。** LLMは気づかず自然な文で埋める |
| **幻覚** | 無い言葉が11文字増える | **直せない。** 誤りに見えない |

数量表現（`50件` `80件` `23分` `150分` `2時間半` など9種）は
**全モデルで完全に一致**した。数値が壊れると復元不能なので、ここは重要。

### 製品名は用語集でも直らなかった

`initial_prompt` に `SMILE V 2nd Edition` を入れても、
出力は「スマイルVセカンドエディション」のまま。
ただし**音と構造は保たれている**（`V` も取れている）ので、
**製品マスタを使った後処理での置換で確実に直せる。**
文字起こし側で粘るより、そちらの方が確実で安い。

## 結果の比較

```bash
uv run compare.py
```

`output/*.json` を横並びにして、CER・**欠落文字数**・業務用語の取得数を出す。
CERだけを見ると欠落を見逃すため、必ず併記する。
`output/old_audio/` は旧音声（`sales_demo.wav`）の結果で、比較対象から外してある。
