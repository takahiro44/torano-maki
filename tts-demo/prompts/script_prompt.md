# 商談台本を書かせるプロンプト（ChatGPT Work 用）

下の「プロンプト本文」をそのまま貼り、最後の `## 今回の設定` だけ書き換えて使う。
**1回で数本まとめて書かせてよい。** 返ってきた JSON を
`drafts/<番号>_<英小文字の名前>.json` に保存し、

```bash
uv run make_audio.py drafts/03_bundle.json
```

を実行すると、入っている台本の本数ぶん `output/<id>.wav` が出る。

**モデル出力の細かい崩れ（コードブロックの囲み・話者名の表記ゆれ・長すぎる発話・
束ね方の違い）は `import_script.py` が吸収する。**
完璧な JSON を粘って出させる必要はない。

---

## プロンプト本文

````text
あなたは日本の法人営業に詳しいシナリオライターです。
音声合成にかける商談の台本を JSON で書いてください。

# 出力形式（この形以外は出さない）

指定された本数の台本を、`scripts` に並べた1つの JSON で返す。

```json
{
  "speakers": {
    "Sales": {
      "voice": "Kore",
      "role": "営業担当者",
      "persona": "30代女性の法人営業担当者で、〜です。話す速度は普通で、信頼感のある口調にしてください。"
    },
    "Customer": {
      "voice": "Algieba",
      "role": "顧客側",
      "persona": "50代男性の業務部長で、〜です。話す速度は普通で、落ち着いた自然な口調にしてください。"
    }
  },
  "scripts": [
    {
      "id": "03_delivery_delay",
      "title": "台本の内容がわかる日本語の題名",
      "turns": [
        { "speaker": "Sales", "text": "…" },
        { "speaker": "Customer", "text": "…" }
      ]
    }
  ]
}
```

# 制約

- 話者は `Sales` と `Customer` の2人だけ。この英語キーを使う
- **`id` は音声のファイル名になる。** `03_delivery_delay` のように
  英小文字・数字・アンダースコアだけで、台本ごとに違う名前を付ける
- `speakers` は全台本で共通なら上の位置に1つだけ書く。
  台本ごとに人物を変えるときは、その台本の中に `speakers` を書く
- `voice` は指定された音声IDをそのまま書く
- `persona` は「Salesは<persona>」の形で文中に埋め込まれる。
  「30代女性の〜です。」のように、その位置から自然に続く文にする
- **1発話は日本語で400文字以内。** 長い説明は相手の相槌を挟んで分ける
- `text` に話者名・ト書き・記号（「――」「（笑）」など）を入れない。
  読み上げられてしまうため、発話される言葉だけを書く
- 数字は読み上げられる形で書く（「30個」「1週間」など）
- 発話数は1本あたり40〜60。実際の商談のように、相槌や短い返しを混ぜる
- 出力は JSON のみ。前置きや後書きを付けない

# 内容の方針

- 登場する企業・人物・数値はすべて架空にする。実在の企業名を使わない
- **営業が一方的に説明せず、質問で顧客に課題を語らせる。**
  後工程で「顧客の課題・業務の実態・数値」を抽出するため、
  顧客の発話に具体的な事実（誰が・どれくらい・どう困ったか）が入るようにする
- 最近実際に起きた出来事を1つ挙げさせ、その経緯を掘り下げる流れにする
- 綺麗にまとめず、言い淀みや脱線が少し混ざってよい

# 今回の設定

- 本数: <例）3本>
- 業種 / 顧客像: <例）産業機械部品の卸売会社、業務部長>
- テーマ: <例）1本目 納期回答の遅れ / 2本目 属人化した在庫確認 / 3本目 新人の立ち上がり>
- Sales の音声ID: Kore
- Customer の音声ID: Algieba
````

---

## 音声IDの選び方

`voice` は Gemini TTS のプリセット音声名。**実際に生成して声を確認したのは次の3つ。**

| 音声ID | 使った台本 | 印象 |
|---|---|---|
| `Achird` | ①受注業務 Sales | 30代男性 |
| `Algieba` | ①②Customer | 40〜50代男性、落ち着いている |
| `Kore` | ②在庫・納期 Sales | 30代女性 |

他にも `Puck` `Charon` `Fenrir` `Leda` `Orus` `Aoede` `Zephyr` などが指定できる。
未確認のIDを使うときは `--limit 4` で先頭だけ生成して声を聴いてから通すこと。

**声の指定は台本JSONの `speakers` にある。** 生成スクリプトは書き換えなくてよい。
