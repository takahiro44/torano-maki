# セットアップ記録

DGX Spark（ARM64 + CUDA）環境で**ハマった内容と解決策**を記録する。

**目的は、同じ罠を4人が個別に踏まないこと。**
解決したら必ずここに追記してから次に進む。うまくいかなかった試行も
「これは駄目だった」と分かるだけで他の3人の時間を節約できるので、残す価値がある。

---

## 記録フォーマット

```
### YYYY-MM-DD 見出し（何をしようとして詰まったか）

- **やろうとしたこと**:
- **起きたこと**（エラーメッセージをそのまま貼る）:
- **原因**:
- **解決策 / 回避策**:
- **未解決の場合**: 次に試すこと
```
